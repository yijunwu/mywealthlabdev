Upgrade for Wealth-Lab Developer 6.4
A patch release is available for WLD 6.4 that addresses the following issues with Wealth-lab Pro/Developer discovered shortly after the previous minor upgrade:   (11-03-2012)

  • (83993) The Strategy Monitor will load Alerts from the previous session (no change from 6.3).

  • (83994) Auto-trade crash when canceling/replacing an order is fixed .

  • (83995) The intermittent "Unable to get Data on demand" error should no longer occur when accessing external symbols from the Strategy Monitor.

Wealth-Lab Developer 6.4 is now available!
Wealth-Lab 6.4 is built on the .NET 4.0 framework, which is expected to improve performance for memory hungry operations like large simulations and optimizations. Windows 7 users who keep up with Windows updates will have already installed the .NET 4.0 framework. If you're still using XP and haven't installed the .NET 4.0 framework, the 6.4 installation will guide you to download and install it. (10-23-2012)

Neuro-Lab Note!
After installing v6.4, click Tools > Extension Manager and accept the update for the Neuro-Lab® Add-in. This is required for Neuro-Lab to appear in the 6.4 Tools menu.

Changes and Bug Fixes in Version 6.4.0.49:

  • The Strategy Explorer now supports mapping network paths for strategy file folders.

  • Index Manager was renamed to Index-Lab®.

  • (62852) An error in a Combination Strategy should no longer shut down the backtest or cause invalid alert sizes.

  • (64742) A fix is in place a market order contingent on the cancellation of an OCO pair was in work (not verified) at the time of this writing. In prior versions, the market order would error out if the OCO did not quickly cancel.

  • (60710) Fixed an obscure bug that could cause an empty delimiter field in the ASCII Provider DataSet wizard.

  • (47103) Email Alerts should no longer fail intermittently.

  • Late for publication in the User Guide, some minor fixes where applied to the Strategy Monitor that include "Run Now" operation and an intermittent condition in which the Strategy Alert count did not match the number of Alerts displayed in the lower frame.

Note on 64-bit Installations
Due to use of legacy 32-bit COM components, MetaStock and TeleChart static adapters cannot be used with 64-bit installations. If you require either of these data adapters, then choose the 32-bit installation for your x64 computer.  Finally, note that you can install, but not operate simultaneously, both the 32- and 64-bit versions on the same x64 computer.
